# Library Management System

A professional dark-theme Library Management System built with Java, Spring Boot, Spring MVC, Spring Data JPA, Hibernate, MySQL, Thymeleaf, HTML, CSS, and JavaScript.

## Features

- Attractive dashboard-style home page with library metrics
- Book catalog with search, availability status, categories, authors, shelf locations, ISBNs, and cover images
- Member management with status tracking
- Loan issue and return workflow with due dates and overdue indicators
- Category management
- Featured collections, announcements, and quick actions
- Responsive dark Material-inspired UI with a sticky navigation bar
- Seed data on first run
